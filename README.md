# Schottky Contact Lab

An interactive English-language lab exploring ideal metal–2D semiconductor contacts.

[Open the interactive website](https://terennnn.github.io/schottky-contact-lab/)

Choose metals and 2D materials, switch carrier type and layer count, and explore band alignment, Schottky barriers, and illustrative charge-transfer animations.

The website uses an ideal Schottky–Mott model. Band shapes and particle motion are schematic, not self-consistent simulations. Material data and references are provided on the page.

All energies are in eV. You can import CORS-enabled HTTPS JSON or upload a JSON file.
